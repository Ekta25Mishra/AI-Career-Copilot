# AI Career Copilot

AI Career Copilot is an AI-powered career assistance platform designed to help users prepare for their dream jobs. It analyzes resumes, identifies skill gaps, matches profiles with job descriptions, generates personalized learning roadmaps, and provides AI-driven interview preparation.

## Features

- **Resume Analysis:** Extracts skills, education, experience, and projects from resumes.
- **Job Matching:** Compares resumes with job descriptions and identifies missing skills.
- **Skill Gap Analysis:** Highlights skills that need improvement.
- **Learning Roadmap:** Generates personalized learning plans based on skill gaps.
- **Interview Preparation:** Provides relevant interview questions and AI-powered practice sessions.

## Tech Stack

- **Frontend:** React.js, Vite
- **Backend:** Node.js, Express.js
- **AI Service:** Python, FastAPI, Google Gemini API
- **Database:** MongoDB
- **Authentication:** JWT

## Project Structure

```text
AI-Career-Copilot/
├── client/       # React frontend
├── server/       # Node.js backend
└── ai-service/   # Python AI service
```

## Getting Started

1. Clone the repository.
2. Install dependencies for the frontend and backend.
3. Configure environment variables for MongoDB, JWT, and Gemini API.
4. Start the backend, AI service, and frontend.
5. Open the application in your browser.

## Objective

To make career preparation smarter and more personalized by combining Generative AI with practical career development tools.
